E1 03/08/2026 — Encontro 1 GitHub — Prática individual (Fase 1)

Tipo: Atividade individual — todos os integrantes realizam as mesmas etapas

Ações necessárias

  • Criar conta pessoal no GitHub com nome de usuário profissional;
  • Criar repositório individual público chamado meu-primeiro-site;
  • Criar o arquivo index.html com Hello World e o próprio nome;
  • Ativar o GitHub Pages no repositório individual;
  • Realizar pelo menos 3 commits com mensagens descritivas em português.

Atividades de todos os integrantes

  • Criar conta no GitHub e confirmar o e-mail de cadastro;
  • Nome de usuário: escolher algo profissional — ex: joao-silva. Ele aparecerá no endereço do site;
  • Criar repositório meu-primeiro-site como público, com README;
  • Criar o arquivo index.html com o próprio nome no conteúdo;
  • GitHub Pages: Settings → Pages → Deploy from branch → main → / (root) → Save;
  • Realizar dois commits adicionais com mensagens descritivas;
  • Verificar que o site está acessível pelo link gerado.

Após finalizar: enviar ao professor o link do GitHub Pages individual — formato: usuario.github.io/meu-primeiro-site

E2 10/08/2026 — Encontro 2 GitHub equipe (Fase 2) + Trello + Google Drive

Tipo: Atividade coletiva — líder e integrantes com papéis distintos

Ações necessárias

  • Confirmar que organização, repositório do grupo e colaboradores estão corretos;
  • Configurar o quadro Kanban no Trello com as 4 colunas obrigatórias;
  • Criar e organizar a pasta do grupo no Google Drive;
  • Cada integrante cria sua branch individual e realiza o primeiro commit;
  • Abrir o primeiro Pull Request.

Atividades do líder

  • Verificar que a organização e repositório do grupo estão públicos e acessíveis;
  • Confirmar que todos os colaboradores e o professor foram adicionados;
  • Trello: criar quadro Kanban com colunas Backlog, Em Progresso, Em Revisão e Concluído;
  • Compartilhar o Trello e o Google Drive com todos e com o professor;
  • Adicionar ao Trello os cards desta entrega com responsável, prazo e checklist;
  • Revisão e merge: revisar os Pull Requests dos colegas e aprovar.

Atividades do grupo

  • Branch individual: criar branch com o próprio nome a partir da main — ex: joao-silva;
  • Arquivo HTML pessoal: criar arquivo sobre-[nome].html na branch individual com conteúdo inicial;
  • Fazer commits com mensagens descritivas em português;
  • Pull Request: abrir PR da branch individual para a main.

Após finalizar: enviar ao professor: link do repositório no GitHub, link do quadro Trello e link da pasta no Google Drive.
